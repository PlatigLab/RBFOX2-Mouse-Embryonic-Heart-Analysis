# RBFOX2 in Heart Development. 

This repository contains the code for analyzing the role of RBFOX2 in heart development.

## Contents: 

📂 `inputs/`:

Input data used in multiple parts of the analysis. 

📂 `outputs/`:

Output data from the analysis.

📂 `prior_data/`:

Analysis related to data from Muge & Sunny's prior `RBFOX2` [publication](https://academic.oup.com/nar/article/50/4/2270/6523805).
